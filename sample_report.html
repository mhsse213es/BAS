▶ Analyst Assessment

This assessment executed 24 ATT&CK techniques across 10 tactic categories on WIN-PROD-01 (Production environment) between 10:22 and 10:35 UTC. Of 24 techniques, 17 were prevented or detected; 7 succeeded with no security control response — 3 Critical, 4 High severity.

Credential Access is the primary exposure: LSASS memory dumping (T1003.001) and Kerberoasting (T1558.003) both executed without triggering any alert. An attacker reaching this endpoint can harvest domain credentials in under 90 seconds and authenticate as any domain user, including privileged accounts. Defense Evasion is the second critical gap — 5 of 7 evasion techniques executed using built-in Windows binaries (regsvr32, rundll32) that signature-based controls cannot detect without behavioral rules.

Immediate action required: Enable Windows Credential Guard and LSA Protection (estimated 4 hours). This closes the two highest-risk findings. The Defense Evasion gaps require Microsoft ASR rule enablement within 30 days. All 7 gaps have specific, actionable remediations in Section 5 of this report.

OS Credential Dumping: LSASS Memory
T1003.001  ·  Tactic: Credential Access  ·  Framework: Atomic Red Team
✗ EVADED — No Control Response
What Happened
Mimikatz executed lsadump::sam targeting LSASS process memory. No EDR alert fired. Process ran as SYSTEM. Credentials extracted in 1.2 seconds.
Business Impact
Attacker can harvest plaintext passwords and NTLM hashes for all domain users currently logged in. Full domain compromise achievable in one lateral movement step using Pass-the-Hash.

▶ Recommended Fix — Estimated Effort: 4 hours
Enable Windows Credential Guard via Group Policy (Device Guard → Credential Guard → Enabled with UEFI Lock). Separately enable LSA Protection by setting HKLM\SYSTEM\CurrentControlSet\Control\Lsa\RunAsPPL = 1. These two controls together prevent any process — including SYSTEM-level — from reading LSASS memory directly. Verify via Get-WmiObject -Class Win32_DeviceGuard.

Remove or raise the AV file-size scan limit in the AV/EDR console policy. Enable cloud-based ML scanning (e.g., Defender Cloud Protection) which operates independently of local file size limits. Enable the EDR rule to flag execution of any oversized PE file (>50 MB) that hasn't been scanned.

T1558.003  ·  Tactic: Credential Access  ·  Framework: Atomic Red Team

Business Impact
Any domain user can perform this. Extracted ticket hashes can be cracked offline to recover service account passwords — often privileged, rarely rotated.

▶ Recommended Fix — Effort: 8 hours
Implement Group Managed Service Accounts (gMSA) for all service accounts — these use 240-character auto-rotating passwords that cannot be cracked from Kerberos tickets. Enable alerting on Event ID 4769 (Kerberos Service Ticket Request) with Encryption Type 0x17 (RC4) — legitimate services use AES; RC4 requests from non-service accounts are highly suspicious. Consider Microsoft ATA or Defender for Identity for automated Kerberoasting detection.

Section 6
Remediation Roadmap

Prioritised action plan. Full implementation expected to raise Prevention Score to 89% and Detection Score to 88%.

⚡ Immediate — 0 to 7 days
1
Enable LSA Protection (RunAsPPL) registry key. Blocks LSASS memory reads from all processes including SYSTEM — closes T1003.001 immediately.
2
Enable Windows Credential Guard via Group Policy. Hardware-isolated credential storage. Required: UEFI Secure Boot + TPM 2.0 (already present on WIN-PROD-01).
3
Raise or remove the AV file-size scan limit in the endpoint security console policy. Enable cloud ML scanning as backup — closes T1027.001.
4
Block outbound network from regsvr32.exe via Windows Firewall GPO rule — closes T1218.010 SCT download vector immediately.
▲ Short-Term — 8 to 30 days
5
Enable Microsoft ASR rules (Audit first 48 hrs, then Enforce) for LOLBAS abuse: Block Office child processes, Block obfuscated script execution.
6
Enable Kerberos Event 4769 alerting on all Domain Controllers for RC4 ticket requests from non-service accounts — closes T1558.003 detection gap.
7
Enable SMB signing enforcement via GPO — closes T1021.002 relay attack vector. Verify no legacy systems break before enforcement.
8
Tune EDR lateral movement behavioral rules for RDP anomaly detection — reduce MTTD on T1021.001 from 6.1s to <2s.
✓ Strategic — 31 to 90 days
9
Migrate all service accounts to Group Managed Service Accounts (gMSA) — permanently eliminates Kerberoasting as a viable attack path.
10
Deploy SIEM detection rules for all 7 missed techniques using ATT&CK data source mappings — verify each rule fires on next BAS run.
11
Schedule monthly BAS runs against a Defense Evasion-focused scenario to track ASR rule effectiveness over time.
12
Implement Privileged Access Workstations (PAW) for all admin activity — reduces lateral movement blast radius.
