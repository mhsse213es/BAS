# Agent Rules — Audspect Cloud

Rules set by the project owner. Must be followed without exception in every session.

## Rule 1 — Preserve existing code
**Never delete or modify any existing code outside the specific block being worked on.**
- Only touch the lines directly relevant to the current task.
- Every other function, comment, style, and HTML block must remain exactly as-is.
- If a change accidentally corrupts an adjacent line (e.g. from a batch edit), fix it immediately before moving on.

## Rule 2 — Confirm before large changes
Before making changes that span multiple files or affect core logic, state the exact plan and wait for approval by stating this is core logic change.
