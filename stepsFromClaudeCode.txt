  Or to listen on all network interfaces (so other machines can reach it):
  dotnet run --project BAS.Server --urls "http://0.0.0.0:5000"

  ---
  Step 4 — Access the Dashboard

  Open a browser and go to:
  http://<your-server-ip>:5000

  ---
  Step 5 — Download & run the Agent

  From the dashboard, click Download Agent (top-right button). This downloads BASAgent.zip which is already pre-configured with your server's IP.

  On the target machine:
  1. Extract BASAgent.zip
  2. Run BASAgent.exe as Administrator
  3. The agent will appear on the dashboard automatically

  ---

  ▎ Note: If you change the server IP later, just update BAS.Agent/appsettings.json and repeat Steps 2–3 to re-package the agent.
