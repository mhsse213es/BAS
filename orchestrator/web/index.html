ⓘ Attack Path Validation — How It Works
Relationship mapping and reachability analysis · no exploitation · no propagation
What is Attack Path Validation?
Identifies potential lateral movement paths from a compromised endpoint by validating reachability and administrative relationships between systems. It does not exploit targets or perform vulnerability scanning. Instead it builds an attack graph from collected connectivity and privilege information, then computes blast radius, choke points, and chains to Domain Admin or Crown Jewel assets.
Prerequisites
Required
✓Windows agent online — agent must be enrolled and connected
✓Local enumeration permissions — the agent needs rights to enumerate local admins and active sessions on its own host
✓Targets explicitly listed — the agent probes only the hosts you supply; no subnet discovery
Recommended
●Firewall allows outbound probes — SMB (445), WinRM (5985), RDP (3389) from agent to each target
●Domain-joined host + SharpHound enabled — required for Active Directory relationship edges
Optional
○Crown Jewel tags — tag high-value assets in Tag Assets to surface Crown-Jewel exposure in results
What the agent does during collection
The agent gathers local identity relationships (who is admin where, who is logged in), probes reachability to your explicit target list only, and — on domain-joined hosts with SharpHound enabled — collects Active Directory relationships. Nothing is exploited and no remote authentication is attempted.
Technical Details ▼
1 · Local identity
  • Enumerates all Local Administrators and emits an admin-to edge for each
  • Enumerates Interactive Sessions and emits a has-session edge per logged-on user
2 · Reachability probes (TCP connect, 1.5 s timeout, against your explicit target list only)
  • SMB — TCP 445
  • WinRM — TCP 5985
  • RDP — TCP 3389
3 · SharpHound (domain-joined hosts only, if enabled)
  • Receives binary from server, executes it, uploads raw output ZIP
  • Server parses and merges AD edges — agent never interprets the output
4 · Upload — all nodes and edges submitted to the server; server rebuilds and analyzes the graph
Graph edge types
Edge Meaning
smbSource host can reach destination over TCP 445. Lateral movement via file share, PsExec, or remote service creation is possible if credentials are available.
winrmTCP 5985 reachable. PowerShell Remoting or WinRM-based lateral movement is possible.
rdpTCP 3389 reachable. Remote Desktop access is possible with valid credentials.
admin-toThe source user or group is a local Administrator on the destination host. Credential reuse yields admin access to that machine.
has-sessionAn interactive logon session for the destination user currently exists on the source host. Credentials may be harvestable from LSASS on that machine.
member-ofAD group membership. Source user or group belongs to the destination group. (SharpHound only)
credentialReusable credential link between a user and a host (e.g. shared local admin password). (SharpHound only)
What the graph tells you
Paths to Domain Admin — potential privilege escalation chains leading to tagged Domain Controllers or Crown Jewel assets, computed by traversing observed relationships. Only available when AD data (SharpHound or domain-joined collection) is present.
Blast Radius — estimated number of distinct hosts reachable from the selected endpoint by chaining SMB / WinRM / RDP edges. A blast radius of 12 means: from this starting point an attacker with credentials could potentially reach 12 other systems.
Choke Points — hosts that appear in many attack paths. Compromising or hardening a choke point significantly increases or reduces attacker reach across the entire fleet.
Crown Jewel Exposure — attack paths that terminate at a host you have tagged as a Crown Jewel (ERP, backup server, payment gateway, etc.). Tags are set in Tag Assets.
SharpHound enrichment
Without SharpHound the graph shows host-to-host connectivity (who can reach whom) but not who can use that connectivity. Enable SharpHound to add Active Directory relationships:
  • Group memberships
  • AdminTo across all domain machines
  • HasSession across the domain
  • Local admin via GPO
  • OU structure & GPO links
SharpHound only runs on domain-joined hosts. On workgroup machines it is silently skipped; reachability and local identity still run.
Limitations
  • Only validates explicitly supplied targets — systems not in the list are invisible to the graph
  • No subnet discovery — you must supply the target list
  • Does not execute exploits or authenticate to any remote service
  • Cannot infer privileges that were not collected
  • Results depend on the permissions available to the collecting agent
  • Graph is a snapshot — sessions and reachability change; re-collect to refresh
ⓘ Interpreting results
Attack paths represent potential attacker movement based on observed relationships. They are not proof that exploitation is possible. An smb edge means TCP 445 accepted a connection — it does not confirm valid credentials exist. A path to Domain Admin means the relationship chain is present in the graph — not that every step is exploitable without additional access. Use paths to prioritise hardening and segmentation, not as a confirmed attack roadmap.
Security impact of collection
✓No exploits executed — TCP connect probes only, no authentication
✓No target modification — nothing is written to remote systems
✓Read-only enumeration using standard Windows APIs
✓Minimal network traffic — one TCP SYN per port per target (three probes per host)
✓No propagation — agent never moves to or executes on any remote host
