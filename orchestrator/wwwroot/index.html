✓ Recommended
Download Installer
BASAgent-Setup.exe  ·  Self-contained GUI wizard  ·  Run as Administrator
1Download BASAgent-Setup.exe and copy to the target Windows machine
2Right-click → Run as administrator — UAC prompt will appear
3Enter Server URL (http://this-server:9000) and Agent Secret from Connection Config above
4Click Validate & Install — the wizard tests connectivity before writing anything, then installs and starts the service automatically
5Agent appears in the Agents tab within 30 seconds
Advanced / scripted deployment: ⇓ CLI Binary .\bas-agent-windows-amd64.exe --install --server <URL> --secret <SECRET> --env Production
